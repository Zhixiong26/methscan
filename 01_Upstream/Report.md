## 1. 处理规则

原始输入为每个样本目录中的 `cov/*.cov.gz`，每行格式为：

```text
chrom  start  end  methylation_percent  methylated_count  unmethylated_count
```

重复位点以第1–3列，即 `chrom + start + end` 判定。审计和实际去重采用两个不同层次的分类：

- **完全重复位点**：同一坐标的第4–6列也完全相同。
- **内容冲突重复位点**：同一坐标至少有一行的第4–6列与第一行不同。
- **同概率重复位点**：同一坐标所有记录的第4列甲基化概率相同；实际去重时任意保留第一条。
- **异概率重复位点**：同一坐标存在不同的第4列甲基化概率；实际去重时删除该坐标的全部记录。

因此，“完全重复/内容冲突”是审计分类，而“同概率/异概率”是最终去重分类。即使第5、6列计数不同，只要第4列概率相同，仍按同概率重复处理并保留一条。

去重输出固定保存到：

```text
/share/LCZX_Data/data/allcools/<sample>/cov_dedup_probability
```
